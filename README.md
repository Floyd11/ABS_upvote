# Abstract Upvote Bot

Автоматизация ежедневных голосований в экосистеме Abstract с использованием Native Account Abstraction.

## Как это работает (Blockchain & Execution)

Проект использует возможности **Abstract Global Wallet (AGW)** для безопасного делегирования прав на голосование без передачи приватных ключей от основного кошелька.

### 1. Создание сессии (Blockchain Side)
При активации бота происходят следующие шаги:
- **Генерация ключа**: На фронтенде создается временный сессионный ключ. Он является "одноразовым" и предназначен только для этого бота.
- **Формирование политики**: Создается объект `session`, который жестко ограничивает действия бота в блокчейне:
    - **Signer**: Адрес временного сессионного ключа.
    - **Target**: Контракт голосования (`0x3B50dE27506f0a8C1f4122A1e6F470009a76ce2A`).
    - **Selector**: Разрешена только одна функция — `voteForApp(uint256)`.
    - **FeeLimit**: Лимит на использование газа (например, 0.01 ETH). Это защищает ваш основной баланс от непредвиденных трат.
- **Подпись**: Пользователь подписывает эту политику своим основным кошельком. Это регистрирует доверие к сессионному ключу в специальном модуле вашего смарт-аккаунта (**Session Key Validator**).

### 2. Процесс голосования (Execution Side)
Когда наступает время голосования, бэкенд и `tx-service` выполняют следующие действия:
- **Сборка транзакции**: Формируется транзакция типа **EIP-712 (Transaction Type 113)**, специфичная для сетей на базе ZKsync (включая Abstract).
- **Custom Signature**: В поле подписи упаковывается не только подпись сессионного ключа, но и адрес валидатора вместе с утвержденной политикой: `abi.encode(SessionKeyValidatorAddress, SessionSignature, SessionPolicy)`.
- **Верификация в блокчейне**: Нода Abstract вызывает функцию проверки в вашем смарт-кошельке. Кошелек перенаправляет запрос в сессионный модуль, который подтверждает, что вызов соответствует подписанной вами ранее политике.
- **Исполнение**: После верификации транзакция исполняется. Важно, что в контракте голосования `msg.sender` — это **ваш основной кошелек**, что позволяет вам легально получать XP, поинты и другие активности в сети Abstract.

## Архитектура проекта
- **Frontend**: Next.js (App Router), AGW React SDK, Privy для аутентификации.
- **Backend API**: Python FastAPI. Управляет пользователями, JWT-авторизацией и расписанием голосований.
- **Transaction Service**: Node.js сервис, использующий `@abstract-foundation/agw-client` для корректной упаковки и отправки транзакций с сессионными ключами.
- **Database**: PostgreSQL для хранения данных пользователей и логов голосования.
- **Infrastructure**: Docker Compose, Nginx в качестве Reverse Proxy (с поддержкой SSL через Certbot).

## Безопасность
Бот спроектирован так, что он **физически не может** вывести ваши средства или вызвать другие функции смарт-контрактов, кроме голосования. Это гарантируется кодом смарт-контракта вашего AGW кошелька на уровне протокола Abstract.
